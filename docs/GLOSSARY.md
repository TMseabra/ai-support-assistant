# Glossary

- **Streaming**: the reply is shown token by token as the model generates it.
- **System prompt**: instructions given to the model before the conversation.
- **RAG**: retrieval-augmented generation, answering from retrieved documents.
- **Triage**: classifying a ticket and deciding what to do with it.
- **Tool call**: the model asking the app to run a function (for example an order lookup).
