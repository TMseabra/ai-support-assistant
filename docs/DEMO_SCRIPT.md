# Demo script (about 2 minutes)

1. Open the app and sign in with GitHub.
2. Start a new conversation and ask a support question; show the streamed reply.
3. Ask a follow-up to show the AI remembers the conversation.
4. Open an older conversation from the sidebar to show saved history.
5. Switch to `agent/`: run `npm run agent` and show a ticket being classified.
6. Run `npm run eval` and show the accuracy, cost and latency report.
